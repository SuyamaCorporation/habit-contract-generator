## 習慣契約書メーカー

習慣名・目標頻度・ペナルティ・報酬・証人名を入力すると印刷可能な「自分との習慣契約書」を生成し、連続達成日数を追跡するコミットメント装置。

### 機能
- フォーム: 習慣名・具体的アクション・頻度（毎日/週X回）・期間・報酬・ペナルティ・証人名
- 契約書風プレビューカード（罫線デザイン・正式文書スタイル）をリアルタイム更新
- Canvas によるマウス/タッチ手書きサイン入力欄
- 印刷ボタン（window.print()・印刷用 CSS で不要部分を非表示）
- 今日の達成チェックボックスと連続日数・累計達成数のカウンター
- 複数習慣の保存・切り替え・削除
- localStorage による複数習慣・進捗データの永続保存

### 技術
- 静的SPA（index.html単体）
- Tailwind CSS CDN
- Canvas API（手書きサイン）
- Print CSS（印刷最適化）
- localStorage（習慣・進捗保存）
